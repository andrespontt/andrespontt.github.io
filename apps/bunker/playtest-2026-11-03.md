# Bunker browser playtest — 2026-11-03

Tested the current working tree with the Game Playtest skill. The original review is retained below; all three findings were subsequently fixed and verified before push. Existing uncommitted game changes were preserved.

## Confirmed findings

### 1. [FIXED] P2 — Landscape terminal crowds the map and overlaps command tabs

- **Reproduce:** open the bunker terminal with M, keep Command expanded, and use an 844 × 390 viewport (phone landscape).
- **Observed:** the resource bar and clock consume much of the screen. The map has only 174.75 CSS pixels of height; most markers overlap in the fitted overview. The 340px command column squeezes all six full-length tab labels together, including Settlements, Military, Operations and Businesses. The initial command content is almost entirely below the panel fold.
- **Expected:** readable, independently selectable tabs and enough room to inspect the map. A collapsed command panel or a landscape-specific layout would help.
- **Impact:** selecting destinations and reading command sections becomes difficult on a rotated phone.
- **Owner:** responsive terminal UI. See `terminal.css:88–91`, `:161–181`; short labels only activate in the narrower portrait breakpoint, while the 844px layout keeps the fixed command column.
- **Evidence:** [landscape screenshot](C:/Users/apont/.codex/visualizations/2026/10/25/01a1708d-9a21-7ab2-90e8-71160a78f22b/playtest-terminal-landscape.png).

### 2. [FIXED] P2 — Legacy drone links retain first-person controls and lose the requested view on reload

- **Reproduce:** open `/apps/bunker.html?dev=city&view=drone` directly, let the scene load, then reload.
- **Observed:** the initial camera is aerial, but a Fire button and aiming reticle remain. The address is rewritten to `?at=city&view=inside-store`. Reload then starts inside the store instead of in the drone view.
- **Expected:** aerial controls and a URL matching the chosen view, preserved across reload.
- **Impact:** shared/bookmarked legacy links do not reliably restore their camera state, and display misleading combat controls.
- **Owner:** scene initialization / HUD synchronization, `game.js:423–427`. The legacy branch calls `setView()` after `travel()` without the final `updateUI()` used by the `at` branch.
- **Existing review:** browser-confirmed version of finding 12 in `bugs.md`.
- **Evidence:** [aerial scene with Fire button](C:/Users/apont/.codex/visualizations/2026/10/25/01a1708d-9a21-7ab2-90e8-71160a78f22b/playtest-drone-stale-hud.png).

### 3. [FIXED] P2 — Keyboard reload changes weapon state while simulation is paused

- **Reproduce:** enter the city store in first person, fire a few rounds with F, open Menu → Settings → Pause simulation, close the menu, then press R.
- **Observed:** the HUD says SIMULATION PAUSED, yet ammunition changes to RELOADING 0%. The reload waits there until simulation resumes.
- **Expected:** paused gameplay inputs should leave the weapon unchanged, consistent with the guarded ammunition-button handler.
- **Impact:** keyboard and pointer controls disagree about pause; the player can unintentionally queue a reload while paused.
- **Owner:** input gating, `game.js:261`. The KeyR handler checks overview/repeat/reload availability, but not paused or transitioning.
- **Existing review:** browser-confirmed version of finding 9 in `bugs.md`.
- **Evidence:** [paused reload screenshot](C:/Users/apont/.codex/visualizations/2026/10/25/01a1708d-9a21-7ab2-90e8-71160a78f22b/playtest-paused-reload.png).

## Limits

- Responsive checks used browser viewport overrides, not a physical iPhone or Safari. Pinch gestures, notch insets, touch pointer-lock differences and device GPU performance remain unverified.
- This was a bounded smoke/playtest pass. It did not validate every AI path, long-running economy outcome, save failure, asset pose or collision surface.
- No renderer profiling or WebGL context-loss injection was performed. FPS shown during captures is not a mobile performance benchmark.
- Findings in the older code-only review that are not listed above were not revalidated or declared fixed.
